# Changelog

Changes follow a human-readable release history. Dates and results describe actual repository work.

## [0.1.0] - 2026-11-25

### Added

- Versioned structured personas, custom JSON registry, strict configuration and decision contracts.
- Public goods, two-stage trust and matched synthetic product A/B environments.
- Deterministic offline policy and OpenAI-compatible chat completion adapter.
- Bounded asynchronous execution, round barriers, retries, timeouts, total call budget and sanitized failures.
- Per-attempt context/output traces, metrics, atomic SQLite terminal snapshots and JSON/Markdown reports.
- Source-grounded keyword evidence extraction from local text, Markdown and text PDFs.
- FastAPI endpoints, CLI and responsive browser experiment console.
- Reproducible offline samples, behavioral regression tests and optional real-browser verification.
- CI, container setup, contribution/security policies and maintenance templates.

### Known boundaries

- No paid real-model benchmark or validation against real-user data.
- No authentication, durable background jobs, mid-run recovery or distributed quotas.
- Persona values and offline policies are teaching assumptions; A/B intervals are descriptive approximations.
